# Telegram Business: как Chat helper подключается к вашему аккаунту

Chat helper работает **только через официальный Telegram Bot API** (aiogram 3.31 = Bot API 10.3) в режиме бизнес-бота.
Никаких userbot-сессий, Telethon/Pyrogram, MTProto, QR-логина, номера телефона или кодов входа — бот их никогда не просит.

## 1. Что нужно

* Бот из @BotFather с включённым **Business Mode** (BotFather → ваш бот → Bot Settings → Business Mode → Turn on).
* **Telegram Premium не нужен.** Подключить бизнес-бота может любой аккаунт (раздел «Автоматизация чатов»; источник —
  документация Telegram Bot Features, раздел Business, и руководство grammY «Business»).
* Токен бота — только в `backend/.env` (`BOT_TOKEN=...`).

## 2. Подключение (2026, клиенты Telegram для Android/iOS/Desktop)

1. В боте нажмите **🔗 Подключить** (или отправьте `/connect`). Кнопка «Скопировать» копирует `@username` бота.
2. **Настройки → Изм. (Edit) профиля → «Автоматизация чатов»** (в старых версиях: Настройки → Telegram для бизнеса → Чат-боты).
   Кнопка «Открыть настройки» в боте ведёт по ссылке `tg://settings/edit`; если клиент её не поддерживает, бот показывает путь текстом.
3. Вставьте username бота, выберите чаты (все личные, кроме…, или только выбранные).
4. Включите права (см. [PERMISSIONS.md](PERMISSIONS.md)). Минимум — «Ответы на сообщения»; для Mute — «Удаление входящих».
5. Вернитесь в бот → **🔄 Проверить подключение**. Бот получит `business_connection`, покажет статус и список доступных функций.

Инфографика подключения (RU/UZ, своя графика) — `assets/onboarding/connect_ru.png`, `connect_uz.png`; бот присылает её в мастере.

## 3. До подключения бот заблокирован

Пока подключения нет, доступны только `/start`, `/help`, `/connect`, проверка подключения, инструкция, язык и поддержка.
На всё остальное бот отвечает:

> 🔒 Ваш Telegram-аккаунт ещё не подключён… — с кнопками **🔗 Подключить / 📖 Инструкция / 🔄 Проверить подключение**.

Блокировка проверяется на сервере в каждой точке входа: меню, команды, callback-кнопки, FSM-шаги и REST API. Приложение повторяет
её (мастер подключения вместо разделов). Исключение — Super Admin (системная панель доступна без подключения).

## 4. Какие события обрабатываются

| Событие Bot API | Что делает Chat helper |
|---|---|
| `business_connection` | сохраняет подключение и права (`BusinessBotRights`), снимок прав в `permission_snapshots`; при отключении отзывает все карточки управления |
| `business_message` | команды владельца (`.afk`, `.mute`…), автоответы, AI, фильтры Mute/NoGIF/NoMute, статистика |
| `edited_business_message` | учёт правок (команды из отредактированных сообщений не выполняются повторно) |
| `deleted_business_messages` | учёт удалений, очистка связанных записей |
| `/start bizChat<user_chat_id>` | кнопка «Управлять ботом» в шапке чата Telegram открывает **панель этого чата** в личке (Chat Context Manager, проверяется, что чат принадлежит вам) |

## 5. Ограничения Telegram (честно)

* **Ответить можно только в чат, где собеседник писал за последние 24 часа** (`BUSINESS_PEER_USAGE_MISSING`). Иначе результат
  команды приходит вам в личку с ботом.
* **История до подключения недоступна** — Telegram присылает только новые сообщения.
* **Только личные чаты.** Группы и каналы бизнес-режим не поддерживает.
* **Статус «в сети» нельзя ни подделать, ни скрыть** через Bot API. Команда `.online` честно отвечает
  `NOT_SUPPORTED_BY_OFFICIAL_API` и предлагает альтернативы (AFK, Chat Activity). Имитация «онлайна» через «печатает…» не делается.
* **Удаление входящих** (`deleteBusinessMessages`) требует права «Удаление входящих» (`can_delete_all_messages`). Собеседник может
  успеть увидеть уведомление о сообщении до удаления.
* **Ephemeral-сообщения** Bot API не принимают `business_connection_id`, поэтому в бизнес-чатах не используются; приватный вариант
  карточек — личка с ботом.
* Inline-кнопки в бизнес-сообщениях поддерживаются (по документации `editMessageText` такие сообщения можно редактировать и после
  48 часов). **NOT VERIFIED ON REAL DEVICE** — проверено на тестовом стенде с фейковым Telegram, не на живом аккаунте.
* Передача Stars/подарков, смена username — не используются. Если такие права выданы, инспектор прав советует их выключить.

## 6. Проверка, что всё работает

* В боте: **⚙️ Права бота** (инспектор) — какие права выданы, какие функции и команды от них зависят, что выключить.
* В приложении: раздел **Права бота**, кнопка «Обновить» запрашивает актуальные права у Telegram.
* `./scripts/status.sh` — процесс, `bot_polling: true`, последние строки лога.
