# Права бизнес-бота и инспектор прав

Права выдаются **в Telegram**: Настройки → «Автоматизация чатов» → Chat helper. Chat helper их только читает
(`BusinessBotRights` из `business_connection`), показывает и честно говорит, какие функции без них не работают.

## 1. Права и что от них зависит

| Право Telegram (`BusinessBotRights`) | Название на экране прав | Нужно для | Совет |
|---|---|---|---|
| `can_reply` | Ответы на сообщения | автоответы, AFK, AI-ответы, результаты команд в чате, карточки управления, Protect, `.g`, `.a`, `.re`, `.remindf`, игры | ✅ включить |
| `can_read_messages` | Отметки о прочтении | отметка входящих прочитанными (`mark_read` в автоматизации) | по желанию |
| `can_delete_sent_messages` | Удаление исходящих | удаление сообщений бота: `.re`, `.timer`, `.g` | ✅ включить |
| `can_delete_all_messages` | Удаление входящих | **Mute**, NoGIF, NoMute (фильтр слов), удаление ваших команд после выполнения | ✅ для Mute |
| `can_edit_name` | Менять имя | `.name`, часы в фамилии, откат профиля | по желанию |
| `can_edit_bio` | Менять био | `.bio`, часы в био | по желанию |
| `can_edit_profile_photo` | Менять фото профиля | `.avatar` | по желанию |
| `can_edit_username` | Менять username | не используется | ⛔ не выдавать |
| `can_change_gift_settings` | Настройки подарков | не используется | ⛔ не выдавать |
| `can_view_gifts_and_stars` | Просмотр подарков и Stars | не используется | не нужно |
| `can_convert_gifts_to_stars` | Конвертация подарков | не используется | ⛔ не выдавать |
| `can_transfer_and_upgrade_gifts` | Передача подарков | не используется | ⛔ не выдавать |
| `can_transfer_stars` | Передача Stars | не используется | ⛔ не выдавать |
| `can_manage_stories` | Управление историями | не используется | не нужно |

`can_delete_outgoing_messages` устарело в Bot API 9.1 (его заменили два права удаления выше); Chat helper его не использует.

**Передача Stars и подарков в Chat helper не реализована вообще** — даже Super Admin не может её выполнить. Если такие права выданы,
инспектор помечает их как опасные и советует выключить.

## 2. Инспектор прав

* **Бот:** меню → «⚙️ Права бота»: статус подключения, список прав ✅/❌, какие функции доступны, каких прав не хватает, когда
  права обновлялись, и какие команды зависят от каждого права.
* **Приложение:** раздел «Права бота» (то же самое + кнопка «Обновить», которая запрашивает права у Telegram заново).
* **API:** `GET /api/v1/permissions`, `GET /api/v1/connections/{id}/inspector`, `POST /api/v1/connections/{id}/refresh`.
* **Команда в чате без нужного права** не выполняется «впустую»: бот объясняет, какое право включить и где.
* История изменений прав сохраняется (`permission_snapshots`), Super Admin видит сводку по всем подключениям.

## 3. Делегирование (помощь администратора) — отдельно от прав Telegram

Пользователь может **добровольно** разрешить Super Admin помогать с отдельными разделами настроек: AI, AFK, команды, автоматизация,
диагностика, профиль. Разрешение отзывается в любой момент («Мой аккаунт» → Помощь администратора).

* Изменения **профиля** (имя/био) администратор может только **запросить** — применяются после подтверждения владельцем кнопкой.
* Stars, подарки, токены, переписка — **никогда не делегируются**.
* Все действия по делегированию пишутся в журнал (`delegation_log`) и видны пользователю.
