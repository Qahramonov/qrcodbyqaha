## 4. Безопасность — проверки

* **Скан секретов** (`git grep` по репозиторию и `grep` по распакованному APK) по шаблонам токена Telegram `\d{8,10}:[A-Za-z0-9_-]{35}`, `sk-…`, `sk-ant-…`, `AIza…`, `-----BEGIN … PRIVATE KEY` — **совпадений нет**. В APK есть только строка-подсказка «check BOT_TOKEN» и нет ID администратора.
* **Найден и исправлен дефект:** маскировщик логов не скрывал токен, «склеенный» с `bot` в URL (`https://api.telegram.org/bot<token>/getMe`), из-за `\b` в регулярном выражении. Исправлено, покрыто `test_redactor_masks_tokens_and_keys`.
* **Усиление:** при `API_REMOTE_ENABLED=true` без TLS-сертификата API больше не слушает публичный адрес (`test_api_binds_publicly_only_with_remote_mode_and_tls`).
* В истории git не осталось артефактов сборки (случайно закоммиченный каталог `android/robolectric/target/`, 484 МБ, удалён из истории до первой публикации).

## 6. Что НЕ проверено (и почему)

| Что | Почему | Как проверить |
|---|---|---|
| Работа с настоящими серверами Telegram (Business-апдейты, правка сообщений, окно 24 ч, Stars) | `api.telegram.org` недоступен из среды разработки | чек-лист [OWNER_SETUP.md §7](OWNER_SETUP.md#7-контрольный-список) |
| Установка и работа на реальном Android 14 / ARM64, Termux | нет устройства | установить APK, пройти привязку; `install_termux.sh` на телефоне |
| Android Keystore на реальном железе | Robolectric не эмулирует аппаратный Keystore | вход в приложение, перезапуск телефона, приложение остаётся в аккаунте |
| Реальные AI-провайдеры (OpenAI, Gemini, Anthropic, совместимые) | нет ключей / нет сети к провайдерам | добавить ключ, `.gpt тест`, экран AI → Playground |
| Реальная оплата Stars | требует Telegram и реального платежа | включить `PAYMENTS_ENABLED`, купить тариф тестовым аккаунтом |
| FFmpeg-сборка Termux (ARM64), скорость обработки на телефоне | нет устройства | `.circle`, `.ld`, `.reverse` на реальных файлах |
| Gradle-сборка и GitHub Actions | Google Maven недоступен | запустить workflow «Android APK» |
| `install_termux.sh` целиком | нужен Termux | запуск на телефоне |

cd android && ./build_apk.sh                                           # APK
./scripts/run_android_tests.sh                                         # Android (JDK 17+, Maven)
