# Chat Control Framework: управление чатом кнопками

Команды управления чатом (`.mute`, `.protect`, `.nogif`, `.nomute`, `.afk`, `.auto`, `.re`, `.online`…) отвечают не просто
текстом, а **карточкой управления** — сообщением с inline-кнопками прямо в бизнес-чате (или в личке с ботом, если так настроено).

## 1. Как устроены карточки

* Callback-данные: `cc:<token>:<action>:<version>[:arg]` (`handlers/controls.py`, `services/chat_controls.py`).
* **Нажимать может только владелец.** Проверяется `callback.from_user.id` против владельца карточки; собеседник получает
  «Управлять этой настройкой может только владелец», попытка пишется в аудит (`controls.foreign_press`).
* **Защита от устаревших нажатий:** у карточки есть версия; после любого изменения версия растёт, старая кнопка отвечает
  «Эта кнопка устарела».
* **Идемпотентность:** каждый `callback_query.id` обрабатывается один раз (`control_actions`), двойной тап не включит действие дважды.
* **Отзыв:** при отключении бота в Telegram все карточки подключения помечаются `revoked`, кнопки перестают работать.
* **Где показывать:** настройка `controls_place` — `chat` (в бизнес-чате) или `dm` (в личке с ботом).
  В чате бот по возможности **заменяет вашу команду** карточкой (редактирует сообщение); если нельзя — отправляет новую и удаляет команду.
* Таймеры (`.mute 1h`) истекают автоматически (фоновая задача `controls_expiry` раз в 20 с), карточка обновляется.

## 2. Команды

| Команда | Что делает | Права Telegram |
|---|---|---|
| `.mute [10m\|1h\|1d] [типы]` | Удалять **новые входящие** сообщения собеседника в этом чате. Перед первым включением — **подтверждение** (удаление необратимо). Типы: all, text, media, voice, circle, gif, sticker…; исключения и белый список слов, отчёт об удалениях. `.mute status`, `.mute off` | Удаление входящих |
| `.unmute` / кнопка 🔓 | Выключить Mute | — |
| `.quiet [время\|off]` | Не отвечать автоматически (автоответы, AFK, AI) — сообщения не удаляются | — |
| `.protect` / `.unprotect` | Сообщения Chat helper в чате нельзя переслать/сохранить (`protect_content`). Скриншоты Telegram не блокирует | Ответы |
| `.g текст` | Одно защищённое сообщение (текст или ответом на фото/видео); исходная команда удаляется | Ответы, удаление исходящих |
| `.nogif [off] [gif] [sticker] [circle]` | Удалять входящие GIF/стикеры/кружки | Удаление входящих |
| `.nomute add/del/list/on/off` | Локальный фильтр слов: удалять входящие с выбранными словами (это **не** настройки уведомлений Telegram) | Удаление входящих |
| `.chat` | Панель этого чата в личке с ботом | — |
| `.online` | Честная карточка: `NOT_SUPPORTED_BY_OFFICIAL_API` + альтернативы (AFK, Chat Activity) | — |
| `.afk [время] [причина]` | AFK с карточкой (выключить / продлить) | Ответы |
| `.re текст` / `.re stop` | Повтор: отправляет текст, каждые 5 с удаляет предыдущую копию и отправляет снова, до 2 минут; кнопка «Стоп». Free: 3 запуска в день, платные тарифы — только технические лимиты | Ответы, удаление исходящих |
| `.a [тип] [скорость] текст` | Анимация текста: 16 типов, скорости slow / normal / **fast (по умолчанию)** / turbo, без FloodWait (интервалы ≥ 0.3 с, ≤ 12 кадров) | Ответы |
| `.r текст` | Текст справа налево (Unicode-безопасно); `.r rlo` — через символ RLO. `.reverse` — отдельная команда для медиа | — |

Полный список команд — [COMMANDS.md](COMMANDS.md).

## 3. Mute изнутри

* Движок `modules/chat_filters.py`: на каждое входящее сообщение проверяет правила чата (Mute → NoGIF → NoMute) **до** автоответов.
* Удаление через `deleteBusinessMessages`; если права «Удаление входящих» нет — владелец получает одно предупреждение, а не спам.
* Каждое удаление пишется в `mute_events` (уникально по сообщению), отчёт — по запросу/в сводке. Статистика за 24 ч — в приложении.
* Белый список и исключения настраиваются в приложении (Mute Manager) и через API `PUT /mute/settings`.

## 4. Приложение и API

* Приложение: «Мои чаты» → чат → модули Mute / Protect / NoGIF / NoMute (с тем же подтверждением Mute), Mute Manager, Protect.
* API: `GET/PATCH /chats/{chat_id}/controls` (Mute требует `confirm=true`, пока подтверждение не дано один раз; `409 missing_right`,
  если права нет), `GET /mute`, `PUT /mute/settings`, `GET /protect`.
