# Переход с v1 на v3

Команда обновления — [INSTALL_TERMUX.md](INSTALL_TERMUX.md#3-обновление-с-v1-до-v3-данные-и-токен-сохраняются). `backend/.env` и
`backend/data/` сохраняются, токен бота не меняется.

## 1. База данных

* Миграция **M003** (`v3_chat_controls_mute_twin_reminders_delegation`) применяется автоматически при запуске.
* Перед миграцией существующая база копируется в `backend/data/backups/chat_helper_<дата>_pre_migration_v3.db`.
* Новые таблицы: `chat_control_states`, `control_messages`, `control_actions`, `mute_rules`, `mute_events`, `ai_twin_profiles`,
  `animation_jobs`, `repetition_jobs`, `reminders`, `permission_snapshots`, `delegated_permissions`, `delegation_consents`,
  `chat_messages`. Старые данные не удаляются; экспорт/удаление данных пользователя учитывает новые таблицы.
* Откат: `./scripts/restore.sh backend/data/backups/<файл>_pre_migration_v3.db` (и старая версия кода).

## 2. Что изменилось для пользователей

| Было (v1) | Стало (v3) |
|---|---|
| Бот работал до подключения Business | До подключения в «Автоматизации чатов» доступны только `/start`, `/help`, `/connect`, проверка, инструкция, язык, поддержка |
| `.mute` — выключал автоответы в чате | `.mute` — **удаляет новые входящие** (с подтверждением, таймеры, типы, белый список, отчёт). Старое поведение — `.quiet` |
| `.r` — статус «печатает» | `.r` — текст справа налево (RTL). Статусы «печатает/записывает» — `.mad` |
| `.a` — простая печать | `.a` — Animation Engine: 16 типов, 4 скорости (fast по умолчанию), студия, отмена |
| `.info` — сведения о файле | `.info` — сведения о пользователе; о файле — `.finfo` |
| `.gpt` | основная команда `.ai`, `.gpt` — алиас |
| — | новые: `.re`, `.g`, `.protect/.unprotect`, `.nogif`, `.nomute`, `.sum`, `.ball`, `.morse`, `.ptext`, `.remind/.remindf`, `.geo`, `.wtm`, `.twin`, `.chat`, `.fav` |
| Ответы командой — только текст | Карточки управления с кнопками (только для владельца, см. [CHAT_CONTROLS.md](CHAT_CONTROLS.md)) |
| Тексты RU/UZ в коде | JSON-каталоги, весь интерфейс бота и приложения на узбекском без русских вставок ([LOCALIZATION.md](LOCALIZATION.md)) |
| Подпись AI «🤖 Ответ AI-ассистента» | «🤖 AI» на языке владельца (старая подпись по умолчанию тоже переводится) |

Пользовательские настройки, правила автоответов и автоматизации, история AFK, тарифы и подписки переносятся как есть.

## 3. Что изменилось для администратора

* **Только один администратор — `SUPER_ADMIN_ID`.** Роль `moderator` из v1 больше ничего не даёт (такие пользователи стали обычными).
* Админ-раздел **невидим** для всех остальных (бот, приложение, API отвечает `404`) — [ADMIN_SECURITY.md](ADMIN_SECURITY.md).
* Новая панель Super Admin: 23 раздела в боте, 16 экранов в приложении.
* Делегирование: пользователь может сам разрешить вам помогать с его настройками; профиль — только через его подтверждение.

## 4. Новые настройки `.env`

| Переменная | По умолчанию | Зачем |
|---|---|---|
| `API_DOCS_ENABLED` | `false` | Swagger UI `/api/docs` и `/api/openapi.json` (показывают все маршруты) — только для разработки |

Остальные переменные v1 работают без изменений. Версия сервера в `/api/v1/health` — `3.0.0`.

## 5. API для приложений

* Админ-маршруты для не-админа: `404 not_found` вместо `403` (нативное приложение v1 показывает «Не найдено»; админ-экраны оно
  и так открывало только для Super Admin).
* Неизвестные адреса `/api/v1/*` без токена — `401`, с токеном — `404`.
* `/subscriptions/plans`: `description` — локализованное описание, `description_raw` — сохранённое значение.
* Новые эндпоинты v3 — [API.md](API.md) (onboarding, chat controls, mute, protect, AI twin, animations, reminders, permissions, delegation).

## 6. Приложение

* Новое приложение **Chat helper Control v3** (Flutter, `com.chathelper.control`, versionCode 30) заменяет нативное v1.
* Если Android пишет «Приложение не установлено» — подписи различаются: удалите старое приложение (в нём только сессия) и
  установите v3, затем подключите заново кодом `/app`. Подробно — [BUILD_FLUTTER.md](BUILD_FLUTTER.md).
* Нативное приложение v1 продолжает работать с сервером v3 (совместимые эндпоинты), но новые разделы v3 есть только в новом приложении.
