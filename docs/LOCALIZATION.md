# Локализация (RU / UZ)

## 1. Бот и сервер: Localization Manager

* Каталоги: `backend/chat_helper/localization/locales/ru.json` (эталон) и `uz.json` (узбекский, латиница), ~1700 ключей.
* В коде — **только ключи**: `tr(lang, "afk.afk_vklyuchen", d=...)`, в командах `ctx.t("...")`, общие фразы `p(lang, "on")`
  (ключи `common.*`). Плейсхолдеры — `{name}` (str.format).
* Ключи команд: `cmd.<id>.desc`, `cmd.<id>.syntax`, `cmd.<id>.examples` (строки через `\n`), `cmd.<id>.notes`.
  Синтаксис команд остаётся английским (`.afk`, `.mute`), описания, примеры и результаты — на языке пользователя.
* Язык пользователя — настройка `lang` (`/lang`, панель, приложение). Тексты, которые бот отправляет **собеседникам** (автоответы,
  AFK, шаблоны автоматизации, подпись AI), берутся на языке владельца.
* Падение назад: нет ключа в языке → русский текст → сам ключ (видно в тестах).
* Узбекским пользователям в справке показываются только латинские алиасы команд (русские алиасы продолжают работать у всех).
* Не переводятся (это данные, а не интерфейс): алиасы-синонимы на русском, словари ввода (`срочно`, `оператор`), вопросы викторины
  (двуязычный контент игры), названия языков на их собственном языке («🇷🇺 Русский»).

### Тесты (`tests/backend/test_v3_localization.py`)

* ru и uz содержат одинаковые ключи, значения не пустые и корректные format-строки, плейсхолдеры совпадают;
* в узбекских текстах нет кириллицы (кроме примера `.fix`: ghbdtn → привет);
* **каждый ключ, используемый в коде, существует** в обоих языках (AST-проверка вызовов `tr/t/p/notify_t` и ключей-констант);
* динамические ключи (`cmd.*`, права, тарифы, триггеры, шаблоны, единицы времени, ответы `.ball`, инфографика) существуют;
* в `handlers/` нет захардкоженного русского текста;
* **все экраны панели, все 23 раздела Super Admin и основные команды отрисовываются на узбекском без кириллицы.**

## 2. Приложение Flutter

* Строки: `flutter_app/lib/core/strings.dart` (`ruStrings`, `uzStrings`, 644 ключа), доступ `t('key', {'n': 3})`.
* Язык: настройка аккаунта (`/auth/me` → `settings.lang`); до подключения — локальный выбор на экране приветствия.
  Смена языка в приложении меняет язык и бота (`PATCH /settings`).
* Тексты с сервера (названия прав, описания команд, шаблоны) уже приходят на языке аккаунта.
* Тесты (`test/unit_test.dart`, `test/screens_test.dart`): одинаковые ключи, плейсхолдеры, латиница в uz, все ключи из кода
  существуют, **каждый экран в uz без русских строк приложения** (на записанных узбекских ответах сервера).

## 3. Как добавить язык (например, английский)

1. Скопируйте `ru.json` → `en.json`, переведите значения, сохраните плейсхолдеры `{...}`.
2. Добавьте код в `LANGS` (`localization/__init__.py`) и в варианты настройки `lang` (`services/settings.py`).
3. Для приложения добавьте карту `enStrings` в `strings.dart`, код в `supportedLangs` (`i18n.dart`) и `Locale('en')` в `app.dart`.
4. Запустите тесты — они покажут пропущенные ключи и несовпадающие плейсхолдеры.

Английский каталог не поставляется: v3 официально поддерживает RU и UZ.
